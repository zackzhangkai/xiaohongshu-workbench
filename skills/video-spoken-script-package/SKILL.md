# video-spoken-script-package：口播稿

口播稿的唯一标准：**拿起来就能开口，说出去有人听完**。它跟文章的区别是——听众不能回看，每一句都要能被耳朵接住。

## 动笔前先定两件事（缺了问，不猜）

1. **一句话主旨**：这期视频听完，观众记住的那一句话是什么？
2. **目标时长**：不同时长是不同结构——
   - 30 秒：一个钩子 + 一个点 + 一句收束（约 80–100 字）
   - 60–90 秒：钩子 + 三个短点 + 收束（约 200–280 字）
   - 3 分钟以上：钩子 + 分模块讲述 + 收束（每分钟约 220–260 字）

## 铺稿结构

1. **钩子（前 5 秒）**：抛问题、给反差、亮结果，三选一。前 5 秒决定完播，不在开头寒暄、不说"大家好我是谁"。
2. **主线**：按"问题 → 展开 → 证据/例子 → 小结"推进；3 分钟以上的稿子分 2–3 个模块，每模块开头用一句过渡（"说完了A，再看B"）。
3. **收束**：一句话回到主旨 + 一个具体的下一步（"下一期讲XX"或"评论区告诉我你的情况"）。

## 口语化改写

- 短句：一句不超过 20 字，说着一口气能念完。
- 人话：术语换成大白话（"认知负荷"→"脑子转不过来"）。
- 具体化：数字、画面、场景（"很多人"→"十个里有八个"）。
- 删掉书面连接词（"综上所述""与此同时"），换成口语过渡（"那怎么办""你猜怎么着"）。

## 标注

在关键位置用括号标注：〔停顿〕〔重音：XX〕〔放慢〕〔此处进 B-roll：XX 画面〕。标注是给讲述者的，不计入口播字数。

## 输出

- **完整口播稿**（含标注、按模块分段）。
- **提词版**：每段开头一行要点提示（"模块2：三个步骤，重点讲第二个"），方便录制时扫一眼。
- 时长估算：按 240 字/分钟给出全稿预计时长。

## 边界

- 不写分镜脚本、不规划剪辑，除非用户明确要（要了就只给建议清单）。
- 用户给的是文章要改成口播：先压成信息点，再按口播结构重铺，不逐段照搬。
- 事实与数字用用户提供的；要引用外部数据时标注"数据来源待核实"。
