# pattern-decoder：内容母版拆解

看懂一篇爆款，不该止于"它火了"，而是能说出"它的结构换一副素材还能不能再火一次"。本技能做这件事。

## 拆解单篇（五层骨架）

对每篇参考内容逐层回答：

1. **入口钩子**：前 3 秒/前 3 行靠什么留住人？（悬念 / 反差 / 利益承诺 / 情绪共鸣 / 身份圈定）
2. **信息排布**：先给什么后给什么？结论前置还是过程前置？信息密度怎么分配（每屏/每段几点）？
3. **推进节奏**：靠什么让人往下走？（未完的缺口 / 递进感 / 密集变化 / 情绪累积）
4. **形式元素**：图文分工、排版/剪辑手法、 emoji/字幕/标签的使用规律。
5. **出口动作**：结尾引导什么？（收藏 / 评论提问 / 追更 / 转发理由）

每层引用原文证据，不凭印象下结论。

## 多篇找母版（用户提供 2 篇以上时）

- 对比各篇骨架，找**跨篇稳定**的部分——那就是母版；只出现一次的是该篇素材特性，不算。
- 区分两层：**平台层母版**（该平台通用的，如小红书首图逻辑）与**赛道层母版**（该垂类的，如装修号的对比叙事）。

## 输出：可复用公式卡

```
**母版名**：<起个能记住的名字，如"三段反差结构">
**骨架**：<钩子类型 → 排布顺序 → 节奏手段 → 出口动作，一段话>
**适用条件**：<什么主题/人群/平台下有效>
**套用步骤**：<1. 2. 3. …按步可执行>
**不适用**：<什么情况下会失效>
**来源**：篇目清单
```

## 套用与落地

- 公式卡可直接交给创作技能使用：仿写技能迁移形式、图文技能按骨架排布、标题技能按钩子类型选公式。
- 套用后做一次"结构对表"：新内容的五层骨架逐层对照公式卡，偏了就调。

## 边界

- 只拆用户提供的内容；对没读到的部分（视频画面、图片细节）不推测。
- 不输出"搬运指南"：公式卡是结构工具，套用必须换全部素材，原文表述一个字不带。
- 样本 ≤ 2 篇时注明"母版稳定性有限"；拆不出共性就直说这几篇结构各不相同。
