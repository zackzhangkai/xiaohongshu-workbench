# social-cover-director：社媒封面设计

信息流里读者先看到封面，再看标题，最后才决定点不点开。封面不好，后面全白搭。

## 第一步：定平台与画幅

| 平台 | 推荐比例 | 说明 |
| --- | --- | --- |
| 小红书 | 3:4 竖版 | 首图占屏最大，信息流双列 |
| 抖音/视频号图集 | 9:16 | 全屏沉浸，文案居中偏上 |
| 公众号头条 | 2.35:1 横版 | 次条 1:1 |
| B 站/微博 | 16:9 横版 | 标题文字叠图下方 |

**安全区**：小红书双列卡片会裁左右、抖音有右侧点赞栏和底部进度条——主文案放画面中央 60% 区域，四边留白。

## 第二步：写图上文案

- **主文案 ≤ 8 字**：一个具体承诺或反差（"3 天出方案""我删掉了这 3 个 App"）。
- **可选副文案 ≤ 14 字**：补充人群或数字（"设计师亲测""省下 200 元/月"）。
- 字号对比要大：主文案至少是副文案的 2 倍，缩略图状态下主文案仍须可读。
- 图上文案与标题不重复——封面说一半，标题说另一半。

## 第三步：选视觉钩子（四选一）

- **结果型**：直接展示成品/效果对比（前后分屏、成品特写）
- **反差型**：违背常识的画面组合
- **清单型**：数字 + 排列物（"5 件"摆一排）
- **人物型**：真实表情特写（惊讶/专注），情绪即钩子

## 第四步：生成

- 提示词先经整理：主体锚点 → 构图（含文案留白区）→ 色彩 → 风格 → 约束（"中央留白放文字"）。
- 一次一张，出 2–3 个候选再选；成套封面锁统一锚点。
- **图内文字可能出错**（错字、变形）：关键文字（价格、日期、品牌名）生成后必须核对，重要信息一律以正文文案为准；文字复杂时改为"留白封面 + 发布时用平台文字工具叠加"。

## 边界

- 不复刻他人封面构图当自己的；参考风格可以，逐元素照搬不行。
- 封面承诺必须被正文兑现，不做标题党。
- 用户只要封面建议不出图时，给到文案+构图方案即可停。
