# xhs-comment-insight：评论区洞察

评论区是选题矿：读者在原笔记下面**没被满足的部分**，就是下一篇的入口。本技能处理一条笔记及其评论摘录，产出一个选题。

## 分析步骤

1. **逐条归类评论**：
   - 追问——想要更多细节（"具体哪个牌子""第几步是啥"）
   - 反驳——不同意作者（"我这儿完全不是这样"）
   - 补充——读者自己的经验（"再补一个：……"）
   - 情绪——共鸣或焦虑（"看到这条终于安心了"）
   - 行动需求——"有没有……版""能不能出一期……"
2. **找簇**：单条评论是噪声，三类以上评论指向同一缺口才是信号。数一数每类各几条。
3. **验真**：这个缺口是否真实、是否够多人、是否适合这位创作者写（有经验、有素材）。
4. **提炼一个选题**：只取最大的簇，不贪多。

## 输出格式（标注式四段）

```
**选题标题**：≤20 字，可注明参考的标题公式编号

**内容方向**：这篇新笔记写什么、怎么切入、大概结构

**为什么值得写**：评论证据——引用 2–4 条代表性评论原文（注明类型与数量，如"追问×6"）

**给创作者的提醒**：素材缺口或风险（"需要先实测""数据需核实"）
```

## 硬边界

- 只用本轮提供的评论，不臆造未提供的评论区情况；评论摘录不足 5 条时，结论标注"样本有限"。
- 不是评论摘要：不复述原笔记，不总结评论区氛围；产出必须是一个**新的创作方向**。
- 找不到真实缺口时直说"这批评论没有明显未满足需求"，并指出最接近的方向，不硬凑选题。
