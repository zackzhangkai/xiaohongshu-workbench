# content-topic-miner：选题挖掘

出选题不是头脑风暴词云，是给出**下一篇就能动笔的题目**。

## 先分清两种来意

- **明确要选题**（"给我出 5 个选题""这个月写什么"）：进入产出模式。
- **只是聊想法**（"我最近在想……""你觉得这个方向怎么样"）：先倾听、追问、收窄；用户没要清单就不给清单。

## 选题四条质量线（每条都过才算合格）

1. **有具体人群**：能说出"这篇是写给谁的"，不接受"所有人"。
2. **有具体场景**：读者在什么时刻需要它（装修到选灯具那步、宝宝刚满 6 个月）。
3. **有差异化角度**：同一个话题，别人写过的角度不用再写；你的角度来自你的经历、职业、实测或素材。
4. **三秒测试**：标题念出来，读者三秒内能说出"点开我能得到什么"。

## 产出模式怎么做

1. **盘家底**：先看用户给了什么——账号方向、过往内容、素材、这轮的想法。信息不足只问最关键的（写给谁、你有什么独特素材）。
2. **铺候选**：按用户要的数量出选题，每个包含：
   - 标题草案（可注标题公式编号）
   - 目标人群与场景
   - 切入角度与差异化点
   - 首图思路（一句话）
   - 风险提示（需要实测 / 需要核实数据 / 素材缺口）
3. **排优先级**：按"素材就绪度 × 差异化程度"排序，推荐第一个动笔的。
4. **诚实边界**：本环境没有联网调研工具——基于用户材料与既有常识产出；需要真实数据支撑的选题，标注"数据待核实"，不伪造"调研发现"。

## 与其他技能的衔接

- 选题确定后写小红书 → 交给图文成品技能生产。
- 从评论区挖选题 → 评论洞察技能是专项方法。
- 用户要判断某个选题做成什么形态 → 形态判断技能接手。

## 边界

- 不做一刀切去重：历史选题用于了解覆盖面，同类角度若素材更新仍可再写。
- 不输出只有关键词没有角度的"伪选题"（如"聊聊护肤"）。
