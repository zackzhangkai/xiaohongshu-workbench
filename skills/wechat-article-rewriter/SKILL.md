# wechat-article-rewriter：文章改写

改写的目的：同一份信息，服务一个新的读者、场景或平台。**换皮（同义词替换）不算改写**，那是搬运。

## 流程

1. **提取信息点**：先把原文拆成信息点清单——事实、数据、观点、引述、案例。这一步是保真的基础，逐条列出来。
2. **确认改写目标**（缺了先问）：
   - 给谁看？（原读者是谁，新读者是谁）
   - 发在哪、什么用途？（公众号长文 / 演讲底稿 / 课程材料）
   - 篇幅与语气要求？
3. **重新组织**：
   - 按新读者的认知顺序重排信息点，而不是沿用原文顺序。
   - 重写开头：新读者需要的钩子和原文不同。
   - 增删有度：可补充过渡与解释，不可添加原文没有的事实；原文冗余部分可删。
4. **事实保真自查**：交付前把信息点清单对一遍——每个数字、人名、引述、结论与原文一致；发现原文自身矛盾，指出而不裁决。

## 三种常见改法

- **降维改写**（专业内容 → 大众可读）：保留结论，把术语换成比喻和场景。
- **升维改写**（散点内容 → 结构化文章）：保留全部要点，加上框架与小标题。
- **转场改写**（跨平台迁移）：保留信息，换叙事节奏与开头结尾的写法。

## 输出

- 改写后的**完整成稿**。
- 末尾附一句改写说明：采用了什么结构、删了什么、哪些点需要用户补充核实。
- 原文与改写稿的信息点差异（如有增删）明确列出，不静默处理。

## 边界

- 不无中生有：原文没有的数据、案例、引述一律不加；需要补充处标注〔待补〕。
- 引用他人原文超过一句时提醒用户注意授权与出处。
- 用户没给原文就要求改写时，先要原文，不凭记忆或印象生成。
