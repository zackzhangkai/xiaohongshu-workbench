# image-director：成套图片编排

单张图不需要导演；**一组图**需要。这套图讲什么故事、每张担什么职责、全组靠什么统一——这是本技能的事。

## 判断套图类型

- **信息轮播**：封面抓眼球 + 3–8 张信息卡 + 尾卡收束行动。适合干货、清单、攻略。
- **教程步骤**：每张一步，步骤号醒目，视觉上"翻页感"。适合跟练、流程。
- **对比组**：错误做法 vs 正确做法、改造前后。适合纠错、改造记录。
- **氛围组**：无强信息，靠统一影调传递生活方式。适合 vlog 图记、好物展示。
- **电商套图**：主图 + 卖点图 + 细节图 + 场景图 + 尺寸对比。适合商品展示。

## 编排三步

### 1. 定张数与顺序

- 先问内容撑得起几张，再定张数；信息不够就减张数，不注水。
- **首图职责只有一个**：让人停下。冲突、结果、悬念任选其一，别贪多。
- **尾图职责**：收束或行动（"收藏这张""下一期讲X"）。
- 中间各张信息量均衡，单张只讲一件事。

### 2. 锁全组统一锚点

整套图必须重复出现在每张的提示词里，否则一组图会散：

- 风格锚点：如"扁平插画风、米白底、暖棕主色"
- 版式锚点：标题区位置、页边距、卡片圆角
- 人物锚点（如有）：形象特征固定描述，逐张复述

把锚点写成一小段固定文本，生成每张时原样带上。

### 3. 逐张定义再逐张生成

每张先写清楚：这张讲什么、文字放哪（上下留白/中部标题区）、视觉重点是什么。然后**按顺序逐张调用 `image_generate`**——本环境一次一张，不能批量；每张提示词 = 统一锚点 + 本张定义 + 序号标记（如"第3张/共7张"）。

生成后自查相邻两张：风格是否一致、信息是否递进、有没有重复。发现跑偏，重新生成那一张，不将就。

## 边界

- 单张图请求不启用本技能，直接整理提示词生成。
- 卡片上的文字由图片生成时给出文字内容建议，但生成图中文字可能有误——重要文字信息（价格、日期、步骤号）提醒用户以正文文案为准。
- 用户要求改的是"文案"而不是"图"时，交给写作类技能处理。
