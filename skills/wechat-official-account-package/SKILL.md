# wechat-official-account-package：公众号成品

目标：一篇**粘贴进编辑器就能发**的公众号文章——标题、摘要、正文、封面、检查清单一次交齐。

## 生产流程

### 1. 定题与读者

- 公众号读者主动点开，可承接比信息流更深的内容——但仍要 3 秒内说清"读它图什么"。
- 有素材（稿件/要点/知识库引用）先盘点素材；素材不足列〔待补〕，不硬写。

### 2. 标题与摘要

- **标题**：给 3 个候选——主标题 ≤ 20 字（直给结论或制造具体好奇），可带副标题补人群。不造悬念空壳（"看完我沉默了"）。
- **摘要**：≤ 120 字，是决定点开的第二入口——给利益点，不复述开头。

### 3. 正文

- 开头三行入题（手机首屏只有三行可见）。
- 结构：小标题分节（600–800 字/节），段落在 5 行内，每屏至多一处加粗。
- 结尾收束 + 一个具体的互动问题（能被评论回答的问题，不是"你怎么看"）。
- 事实与数字用用户提供的；引用标注来源；配图位建议（每 800–1000 字一处，注明"示意图/截图/数据图"）。
- 排版细节遵循排版技能的格式规则。

### 4. 封面

- 头条 2.35:1、次条 1:1；图上主文案 ≤ 8 字，与标题互补不重复。
- 用 `image_generate` 出 2–3 候选；图内文字生成后核对，复杂文字改用平台编辑器叠加。

### 5. 发布前检查清单（随稿交付）

- [ ] 标题 ≤ 64 字、无错别字，摘要 ≤ 120 字
- [ ] 全文通读一遍（朗读更容易发现拗口处）
- [ ] 图片有授权或自制；引用数据有来源
- [ ] 原创声明、话题标签按账号习惯设置
- [ ] 定时发布时间是否符合账号节奏

## 交付格式（标注式）

```
**标题**：<选定>（候选：…）
**摘要**：<120 字内>
**正文**：
<全文>
**封面**：<比例与文案说明 + 生成图>
**发布检查**：<核对结果或待办>
```

## 边界

- 不代发、不承诺阅读量；"爆款标题"承诺不被正文兑现时不做。
- 用户给了定稿正文时，标题/摘要/封面照做，正文只做排版级整理并注明改动。
