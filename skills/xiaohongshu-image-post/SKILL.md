# xiaohongshu-image-post：小红书图文成品

目标是交付一篇**复制就能发**的图文笔记：标题、正文、标签、配图一次做齐，不留"接下来你可以自己……"的尾巴。

## 生产流程

### 1. 定角度（10 秒功课）

- 读者是谁、这篇解决什么（学到 / 省到 / 避坑 / 共鸣）。
- 用一句话写下记忆点；写不出来就先跟用户对齐，不硬写。

### 2. 规划图片清单

- 首图（封面）：承载最大钩子——结论、反差或最美成品。竖版优先。
- 轮播 3–9 张：每张一个职责（步骤 / 对比 / 细节 / 清单卡），先列清单再生成。
- 无实拍素材时做编排卡片；有素材方向时建议用户补实拍，不虚构"实拍"。

### 3. 写文案

- **标题 ≤ 20 字**：给 2–3 个候选，风格参照标题类技能的公式思路（编号可引 F01–F36）。
- **正文**：首段 3 行内给结论；主体分段，每段一件事；适度 emoji 做视觉断句（每屏不超过 2 个）；结尾一句自然的互动引导，不喊"关注点赞"。
- **标签 3–8 个**：主题词 + 人群词 + 场景词，不堆无关热词。

### 4. 生成配图

- 按轮播顺序**逐张**调用 `image_generate`；每张提示词先经整理（主体锚点 → 构图 → 光线 → 风格 → 约束）。
- 成套图片先锁统一锚点（风格、版式、配色），每张提示词原样复述锚点。
- 生成图中的文字可能出错——关键信息（价格、日期、步骤号）一律以正文为准，并在交付时提醒。

### 5. 标注式交付

按以下结构输出，便于工作台识别成结果卡片并整理素材：

```
**标题**：<选定标题，≤20 字>

**正文**：
<完整正文>

**标签**：<#标签 以空格分隔>

**配图**：按轮播顺序列出（图1=封面：…；图2：…），图片以工具回执链接为准
```

存稿与打包由用户在工作台界面完成（回复下方按钮），不要回答"无法打包"。

## 硬边界

- 不伪造截图、不编造数据与体验；没吃过的店不写"亲测好吃"。
- 图片一次一张生成，不承诺做不到的批量；失败重试单张，不整组重来。
- 用户明确只要初稿、只要文案、只要封面或要视频时，不启用本技能。
