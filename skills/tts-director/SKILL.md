# tts-director：配音稿语音设计

同一段稿子，念法不同效果差十倍。本技能把"写好的文案"变成"知道怎么念的稿子"。

## 设计步骤

1. **定声音画像**：谁在说（身份/年龄感）、说给谁、什么场合（念给一个人的亲密感 vs 讲给一群人的台风）。用户没定就先给默认建议并说明可调。
2. **按气口分段**：一段一口气能念完（≤ 20 字/口）；段与段之间标停顿时长（〔停 0.5s〕〔停 1s——留情绪〕）。
3. **逐段标注**（只标关键处，不通篇标）：
   - 语速：〔快——连珠炮〕〔放慢——一字一顿〕
   - 情绪：〔兴奋〕〔无奈〕〔认真〕〔自嘲〕
   - 重音：〔重音：XX〕每段至多一处
4. **读法消歧**：
   - 数字怎么念写明："2026"→〔念：二零二六〕或〔念：两千零二十六，重音在二十六〕
   - 多音字/易错音注音；英文缩写给读法（"SEO"→〔念：S-E-O〕）
   - 长句拆短，拗口处改写并注明改动

## 输出

- **标注版全文**：分段 + 标注，可直接照念。
- **SSML 版（可选）**：`<speak>` 包裹，`<prosody rate/pitch>` 控语速音高、`<break time="500ms"/>` 控停顿、`<emphasis>` 控重音——供外部 TTS 引擎直接使用；标注克制，引擎对过度标注反而机械。
- **多风格版（用户要求时）**：同稿两种处理（如"热情带货版 / 冷静讲解版"），各附完整标注。

## 原则

- 标注是给念稿人或合成器的指令，不是给别人看的批注——写的都是可执行的动作。
- 广告与口播带"卖点"时，重音落在具体利益（数字、结果），不落在形容词。
- 角色台词：先定角色声音锚点（音高/语速/口头禅），全程一致。

## 边界

- 本环境无 TTS 工具——不假装"已合成音频"，交付止于标注稿；合成由用户在外部工具完成。
- 不改写用户已定稿的文案内容，只做念法层面的微调并注明。
