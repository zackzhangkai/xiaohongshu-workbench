# x-article：X 内容改写

X 的阅读是"高速划过中的驻留"——每个字都在跟下一条内容抢时间。

## 先判断形态（用户没指定就按内容量建议）

| 形态 | 篇幅 | 适用 |
| --- | --- | --- |
| 单条推文 | ≤ 280 字符（中文约 90 字） | 一个观点/一条信息/一个链接钩子 |
| 推文串 | 首条 + 5–15 条 | 过程记录、清单、教程 |
| X 长文 | 标题 + 千字级 | 深度复盘、长故事 |

## 改写规则

**单条推文**

- 第一句就是钩子（结论/数字/反常识），铺垫全部删掉。
- 一条只说一个观点；说不完就拆成串，不硬塞。

**推文串**

- 首条职责：让人展开。给最大利益点（"我做了一年 XX，总结出 7 条"）。
- 中间每条一个完整观点，单条可独立被转发；条与条用序号（1/）衔接。
- 末条收束 + 一个具体互动（"你的第几条不一样？评论区说"）。

**X 长文**

- 小标题结构（每 300–500 字一节）；首段三行内给全文最有价值的结论。

**通用**

- 数字具体（"涨了 3 倍"不是"大幅增长"）；删除"家人们""绝绝子"等中文平台惯用语，X 语感是平实直接。
- 语言跟随原稿与目标受众（中文读者用中文，不必强转英文）；术语首次出现给一句解释。
- 保留原稿事实；X 上错误传播快，拿不准的数据标〔待核实〕。

## 交付格式

```
**形态**：<单条/串 N 条/长文>
**内容**：
<按形态分条输出，串用 1/ 2/ … 编号>
```

## 边界

- 不编造互动数据、不假冒亲历；原稿没有的事实不加。
- 配图建议可给（首图比例 16:9），图由用户素材或另行生成。
- 只做 X 平台改写；多平台分发时其他平台交给对应技能。
