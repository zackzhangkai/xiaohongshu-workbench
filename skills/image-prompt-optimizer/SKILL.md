# image-prompt-optimizer：生图提示词整理

用户说"画一张温馨的厨房"，模型需要知道机位、光线、材质、色调、画幅、完成度。本技能在调用 `image_generate` 之前，把模糊需求整理成模型真正能执行的提示词。

## 整理顺序

1. **锁主体锚点**：画面里必须出现的核心对象是什么？它有哪些不可更改的特征（数量、姿态、位置、身份）？先写下来，全程不动。
2. **判模式**：
   - 纯文字生图：按第 3 步补全。
   - 有参考图（本环境受图片输入开关控制）：先明确每张参考图各负责什么——构图参考、风格参考还是主体参考——再合并成提示词，不混用。
3. **补七个维度**（缺什么补什么，不必全列）：
   - 构图与机位：平视/俯拍/特写，主体占画面比例，前中后景
   - 光线：时间、方向、软硬（如"清晨侧逆光"）
   - 材质：能看见的表面质感（哑光、木纹、织物）
   - 色彩：主色调与点缀色，直接给色名或色系
   - 环境：场景与时代感、天气、整洁度
   - 风格：摄影/插画/3D/水彩 + 参照词（"日系杂志感""皮克斯风"）
   - 完成度：细节密度、锐度、"商业级完成度"这类收尾词
4. **写约束区**：
   - 必须保留：锚点特征、用户点名的元素
   - 必须避免：常见翻车项（多余手指、水印、文字乱码、与锚点冲突的元素）

## 规则

- 主体名词放最前，修饰语跟后；模型对开头的词权重最高。
- 中文提示词为主，风格参照词可保留通用英文说法。
- 用户给的比例、字数、标题等信息转成构图约束（"竖版 3:4，上方留标题区"），不机械复述。
- 不把 UI 术语、后台字段、排版说明写进画面描述——模型看不见"首页 banner"，只看得见画面。

## 输出

只有最终提示词，一段式或"提示词 + 约束"两段式，不写工作过程，不写解释。整理完直接调用工具，不问"要不要生成"。
